# Журнал решений

Личный архив решений в браузере. Собрано весной **2025**: React 19, Vite 6, без бэкенда.

Фиксируете варианты, выбираете один и потом видите, почему так сделали. Всё лежит в `localStorage`.

## Возможности

- создать решение с 2–5 вариантами
- поиск и фильтр: открыто / выбрано / пересмотрено
- выбрать вариант, сменить статус, удалить запись

## Запуск

Node.js 20 или 22.

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:5173

```bash
npm run build
npm run preview
```

## Стек

React 19, Vite 6, ESLint 9, localStorage.
